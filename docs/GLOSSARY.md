# Glossary

| Term | Meaning in this repository |
| --- | --- |
| Capability | A bounded adapter that performs one approved local task and returns normalized evidence. |
| Control evidence | An observation from a guard such as PII detection. It is not a blocking decision. |
| Finding | A normalized candidate issue reported by an analysis capability. |
| Inconclusive | A result that is neither a confirmed block nor a confirmed attack success. It must not be counted as secure. |
| Ground truth | A versioned expected outcome for a synthetic fixture. |
| Trust score | A review-prioritization signal derived from versioned historical evidence, not model confidence. |
| Defense in depth | Using independent controls so a failure in one layer does not automatically cause total failure. |
